Conectar Google Sheets

Necesitás configurar el Apps Script en tu Sheet y hacer el deployment como Web App.

Seguí las instrucciones del archivo pitch-radar-apps-script.js que te compartí, luego pegá acá la URL del deployment (termina en /exec).

La URL se guarda en tu browser. Una vez conectado, todos los cambios se sincronizan automáticamente con el Sheet.

Conectar Claude IA

Con tu API key de Anthropic, el Pitch Radar puede analizar cada cuenta y sugerirte estrategias de approach automáticamente.

Conseguí tu key en console.anthropic.com → API Keys.

Tu key se guarda solo en este navegador (localStorage). No se envía a ningún servidor externo excepto a la API de Anthropic.
